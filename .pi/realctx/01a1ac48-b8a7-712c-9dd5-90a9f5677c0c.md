`realkb` stores persistent local PDF knowledge bases under `~/.pi/agent/realkb/` (`REALKB_DIR` override for tests):
- `src/config.ts`, `src/lock.ts`, `src/storage.ts`: `0600` config/state files, cross-process lockfiles, permanent 3-digit KB IDs (`001`, `002`, ...) tracked in `state.json`, content-addressed PDFs in `objects/<sha256>.pdf`, per-KB `sources/<sha256>/{source.json,pages.json}`, and 7+ char collision-extended citation hashes (`[rkb:001_c676ea9p7]`).
- `src/pdf.ts` + `src/chunker.ts`: self-contained `pdfjs-dist` extraction with `[FIG pX-Y]` markers, header/footer removal, hyphenation repair, and ~600-token sentence chunking with exact page-span tracking.
- `src/embedder.ts` + `src/db.ts`: OpenAI-compatible embeddings (`encoding_format: "base64"`) with input-length split-and-average fallback, plus `KbSearchIndex` (`node:sqlite` + `sqlite-vec` + `FTS5` hybrid RRF search). Under Bun on macOS, `ensureBunCustomSqlite()` configures Homebrew `libsqlite3.dylib` so `sqlite-vec` extensions load during `bun test`.
- `extensions/realkb/index.ts` + `skills/realkb/SKILL.md`: registers `/realkb` commands (`list`, `create`, `connect`, `disconnect`, `config`, `cleanup`), `realkb_*` agent tools, `realkb-state` branch-aware session persistence, and `registerMarkdownTransformer` citation linkification.
- Dev commands: `bun run typecheck` and `bun test`.

`realkb_import` uses `ImportJobManager` (`src/import-jobs.ts`), modeled after `realtasks`:
- `run_in_background` defaults to `true` when importing `>= 2` PDFs (`params.run_in_background ?? inspection.validPdfFiles.length >= 2`), starting immediately after the approval dialog and returning `{ jobId, status: "running", background: true }`.
- Single-file imports (`run_in_background: false` by default) stream live `onUpdate` progress and automatically promote to the background after `timeout` seconds (default `15s`) so slow embedding API calls never block the session.
- `Embedder.embedTexts` (`src/embedder.ts`) and `importPdfsToKb` (`src/engine.ts`) emit granular `ImportProgressEvent` updates after every embedding batch (`[1/3] paper.pdf · embedding 16/48 chunks (33%)`) and persist each batch's vectors to `embeddings` cache immediately.
- `installRealkbDock` (`src/import-jobs.ts`) renders an animated TUI dock widget (`realkb-dock`) and status bar indicator while jobs run (lingering for 10s after completion), and `notifyCompletion` sends a `<realkb-notification>` custom message (`realkb-notification` renderer + `agent_before_settle` support).
- Slash commands `/realkb jobs` and `/realkb stop [id|all]` inspect or stop running import jobs; an interactive `/realkb` or `/realkb manage` TUI overlay is recorded as a future TODO in `docs/design.md`.

`realkb` v0.2.0 supports `.pdf`, `.md` (and `.markdown`), and `.txt` sources:
- Single specific file paths (`.pdf`, `.md`, `.txt`) are imported directly by `inspectImportPaths` (`src/storage.ts`) without requiring `allow_ext`.
- Directory paths only allow `.pdf` by default; passing `allow_ext: ["md", "txt"]` on `realkb_import` (`extensions/realkb/index.ts`) adds `.md` and `.txt` to allowed directory extensions while still rejecting unexpected file types.
- `.md` and `.txt` files are stored under `objects/<sha256>.<ext>` (`sourceType: "md" | "txt"`), extracted as single-page `PagesData` (`pageCount: 1`) via `extractTextPages` (`src/pdf.ts`), and chunked/indexed through the same structure-aware sentence chunker and `sqlite-vec` + `FTS5` pipeline.
